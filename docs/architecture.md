# معماری و نقشهٔ پروژه

## تصمیم قبل از پیاده‌سازی

این سایت کاتالوگ خدمات و نقطهٔ شروع تماس است، نه سامانهٔ ثبت سفارش. دو صفحهٔ HTML کامل برای سئو، دسترسی بدون جاوااسکریپت و سازگاری با مسیرهای فعلی کافی‌اند. یک مولد کوچک با Node استاندارد، محتوای هر دو زبان را در قالب مشترک قرار می‌دهد. تعامل‌ها در مرورگر و با progressive enhancement اجرا می‌شوند. اطلاعات کاربر جمع‌آوری نمی‌شود؛ نیازی به API، پایگاه‌داده، حساب کاربری یا Migration نیست. لینک‌های تماس، پس از انتخاب کاربر، به برنامه‌های خارجی هدایت می‌کنند؛ صفحه در بارگذاری هیچ CDN یا سرویس خارجی را فراخوانی نمی‌کند.

## نقشهٔ فایل‌ها

| مسیر | مسئولیت |
|---|---|
| `site/content.mjs` | محتوای فارسی و انگلیسی و فهرست خدمت‌ها و مسیرهای تماس |
| `site/icons.mjs` | آیکن‌های SVG مشترک قالب |
| `site/render.mjs` | ترکیب بخش‌ها و تولید HTML دو زبان |
| `site/build.mjs` | تولید خروجی یا بررسی همگامی آن |
| `site/dev.mjs` | پیش‌نمایش محلی با دسترسی محدود به صفحات و دارایی‌های وب |
| `index.html`, `en.html` | خروجی‌های نسخه‌بندی‌شده؛ حفظ مسیرهای فعلی و امکان میزبانی مستقیم |
| `assets/site.css` | طراحی واکنش‌گرا، پالت، تایپوگرافی و حالت کاهش حرکت |
| `assets/site.mjs` | جزئیات خدمات، راهنمای انتخاب و حالت نمایشگر |
| `assets/service-guide.mjs` | منطق مستقل انتخاب خدمات و جابه‌جایی اسلاید |
| `assets/media/` | لوگوی برند و تصویر محلی بخش اول |
| `assets/fonts/` | فونت‌های محلی و مجوزهای مربوط |
| `tests/site.test.mjs` | تست منطق و قرارداد HTML، فایل‌های محلی، مسیرهای تماس و خروجی |
| `tests/site.browser.mjs`, `playwright.config.mjs` | تست مرورگر برای ناوبری، صفحهٔ کوچک و تعامل‌ها |
| `package.json`, `package-lock.json`, `.gitignore` | فرمان‌های توسعه، قفل وابستگی صرفاً آزمایشی Playwright و نادیده گرفتن فایل‌های محلی |
| `Dockerfile`, `.dockerignore`, `deploy/nginx.conf` | تصویر فقط‌خواندنی سایت و تنظیمات وب‌سرور |
| `compose.yaml` | اجرای تصویر منتشرشده با پورت قابل تنظیم |
| `.github/workflows/publish.yml` | تست، بررسی اجرای کانتینر و انتشار GHCR برای شاخهٔ اصلی و تگ پیش‌نمایش تحویل |
| `README.md`, `docs/architecture.md` | راهنمای کار و تصمیم‌های معماری |
| `CNAME`, `_config.yml` | دامنهٔ فعلی و فهرست مسیرهای غیرقابل‌انتشار در GitHub Pages |
| `omixy`, `*.text` | فایل‌های قدیمی، بدون تغییر و خارج از تصویر وب؛ قرارداد استفادهٔ آن‌ها جزو بازطراحی نیست |

نمونه‌کار، اعضای تیم و آمار فاقد تأیید از نسخهٔ بازطراحی‌شده حذف می‌شوند. برای اضافه‌کردن محتوای واقعی، فقط منبع محتوا و در صورت نیاز بخش مربوط از قالب تغییر می‌کند.
